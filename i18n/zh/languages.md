# 支持的语言

## 简介

Playwright 支持多种编程语言，这些语言共享相同的底层实现。所有浏览器自动化的核心功能在所有语言中都得到支持，而测试生态系统的集成方式有所不同。请根据您的经验、对测试生态系统的熟悉程度以及项目约束来选择语言。为了获得最佳体验，请选择我们为每种语言推荐的测试运行器。

## JavaScript 和 TypeScript

Node.js 版本的 Playwright 自带[测试运行器](https://playwright.dev/docs/running-tests)，提供出色的并行化机制、截图断言、HTML 报告器、自动追踪等功能。
* [文档](https://playwright.dev/docs/intro)
* [GitHub 仓库](https://github.com/microsoft/playwright)

## Python

Playwright [Pytest 插件](https://playwright.dev/python/docs/test-runners)是运行端到端测试的推荐方式。它开箱即用地提供上下文隔离、在多个浏览器配置上运行等功能。
* [文档](https://playwright.dev/python/docs/intro)
* [GitHub 仓库](https://github.com/microsoft/playwright-python)

## Java

您可以根据项目需求选择任何测试框架，如 JUnit 或 TestNG。
* [文档](https://playwright.dev/java/docs/intro)
* [GitHub 仓库](https://github.com/microsoft/playwright-java)

## .NET

.NET 版本的 Playwright 提供 MSTest、NUnit、xUnit 和 xUnit v3 [基类](https://playwright.dev/dotnet/docs/test-runners)，用于编写端到端测试。
* [文档](https://playwright.dev/dotnet/docs/intro)
* [GitHub 仓库](https://github.com/microsoft/playwright-dotnet)
