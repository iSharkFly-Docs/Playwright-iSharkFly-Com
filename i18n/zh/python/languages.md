# 支持的语言

## 简介

Playwright 提供多种语言版本，它们共享相同的底层实现。所有用于浏览器自动化的核心功能在各种语言中都得到支持，而测试生态系统的集成则有所不同。请根据您的经验、对其测试生态系统的熟悉程度以及项目约束来选择语言。为获得最佳体验，请选择我们为每种语言推荐的测试运行器。

## JavaScript 和 TypeScript

Playwright for Node.js 自带[测试运行器](https://playwright.dev/docs/running-tests)，提供强大的并行化机制、截图断言、HTML 报告、自动追踪等功能。
* [文档](https://playwright.dev/docs/intro)
* [GitHub 仓库](https://github.com/microsoft/playwright)

## Python

Playwright [Pytest 插件](https://playwright.dev/python/docs/test-runners)是运行端到端测试的推荐方式。它提供开箱即用的上下文隔离、多浏览器配置运行等功能。
* [文档](https://playwright.dev/python/docs/intro)
* [GitHub 仓库](https://github.com/microsoft/playwright-python)

## Java

您可以根据项目需求选择任何测试框架，如 JUnit 或 TestNG。
* [文档](https://playwright.dev/java/docs/intro)
* [GitHub 仓库](https://github.com/microsoft/playwright-java)

## .NET

Playwright for .NET 提供 MSTest、NUnit、xUnit 和 xUnit v3 [基类](https://playwright.dev/dotnet/docs/test-runners)，用于编写端到端测试。
* [文档](https://playwright.dev/dotnet/docs/intro)
* [GitHub 仓库](https://github.com/microsoft/playwright-dotnet)
