# Location

<Badge type="info" text="Added in: v1.10" />

表示源代码中定义 [TestCase](/api/class-testcase) 或 [Suite](/api/class-suite) 的位置。

## 属性

### location.column {#location-column}

<Badge type="info" text="Added in: v1.10" />

源文件中的列号。

**类型**

- `int`


### location.file {#location-file}

<Badge type="info" text="Added in: v1.10" />

源文件的路径。

**类型**

- `string`


### location.line {#location-line}

<Badge type="info" text="Added in: v1.10" />

源文件中的行号。

**类型**

- `int`
